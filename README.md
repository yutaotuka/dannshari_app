# いる・いらない仕分け帳

8つの質問に答えるだけで「残す・保留・手放す」を判定する断捨離Webアプリです。
ビルド不要の素のHTML / CSS / JavaScriptだけで動きます。

## 機能

- **スコア判定**：8問の回答ごとの配点（-4〜+3）を合計して判定（-18〜+18点）
  - +4点以上 → 残す / -3点以下 → 手放す / その間 → 保留
  - 「強い思い出がある」物は手放すにしない、「壊れている」物は残すにしない、という補正つき
  - 判定理由（点数の大きい回答）とスコアのメーターを表示
- **記録**：判定後に自分で「残す・保留・手放す（捨てる/売る/譲る/寄付する）」を決めて保存
- **写真の登録**：最大720pxに縮小したJPEGを保存
- **保留の再判定リマインド**：14/30/90日後を期限にし、期限が来るとホームとナビのバッジで知らせる
- **カテゴリ別の進み具合**：7カテゴリごとに手放した・保留・残すの割合を横棒で表示
- **バックアップ**：JSONの書き出し（コピー／ファイル保存）と読み込み
- 判定の履歴、検索・絞り込み、ダークモード、キーボード操作（数字キーで回答）

## ファイル構成

```
index.html        画面の骨組み（ヘッダー・ナビ・描画先）
css/style.css     デザイン（色・フォントは :root のトークンで管理）
js/data.js        カテゴリ・質問・配点・判定関数 judgeItem()（DOMに依存しない）
js/store.js       IndexedDB への保存（使えない環境ではメモリに退避）
js/app.js         画面描画・ルーティング（#home / #judge / #records / #settings）・イベント処理
```

## 動かし方

`index.html` をブラウザで開くだけで動きます。サーバーに置く場合も、このフォルダをそのままアップロードしてください（PHPやDBは不要）。

## 改造のヒント

- **質問や配点を変える**：`js/data.js` の `QUESTIONS` を編集。しきい値は `SCORE_KEEP` / `SCORE_DISCARD`。
- **判定ロジックのテスト**：`data.js` は Node からも読み込めます。
  ```bash
  node -e "const d=require('./js/data.js'); console.log(d.judgeItem({lastUsed:3, rebuy:2}))"
  ```
- **カテゴリを増やす**：`CATEGORIES` に `{ id, label, mark }` を追加。
- **データを端末間で共有したい**：`js/store.js` と同じインターフェース（all / put / remove / clear）で、PHP + MySQL のAPIを叩く実装に差し替えれば、画面側はそのまま使えます。

## データについて

記録と写真はブラウザの IndexedDB にだけ保存され、外部には送信しません。ブラウザのデータを消すと記録も消えるので、設定画面からバックアップを取ってください。
